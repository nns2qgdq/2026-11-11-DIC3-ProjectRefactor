# 可解釋的國道壅塞預測 Agent

> Explainable Freeway Congestion Prediction Agent  
> **專題研究、系統設計、實驗結果與開發歷程紀錄庫**

## 專案定位

本 Repository 主要用於**集中保存與追蹤本專題的研究及開發紀錄**，包含研究動機、需求與架構設計、資料處理、模型實驗、Agent 設計、評估結果、報告摘要與後續待辦事項。

此處以**文件與研究可追溯性**為優先；不代表所有程式碼、模型或部署環境均已收錄，也不將初步實驗結果視為最終結論。

## 研究背景與目標

國道連續假期壅塞預測除了估計未來車速，也需要將預測結果轉換成具備明確數值依據、適用條件與限制的行前資訊。預測誤差較低，不一定代表出發建議更有效；語言模型產生的說明，也必須避免與實際預測值或官方交通資訊不一致。

本研究聚焦於：

1. **車速預測**：針對國道 5 號主線選定的 10 個區間，預測未來 30–60 分鐘車速。
2. **可解釋回覆**：將預測結果、官方管制資訊與使用者問題整合成有依據的自然語言說明。
3. **可靠性控制**：由程式負責數值計算與規則判定，加入數字核對及模板回退機制。
4. **客觀評估**：分開評估預測模型表現與 Agent 回覆正確性、資訊依據可追溯性。

## 系統概念架構

```text
高公局 M05A 門架資料
         │
         ▼
   資料清理與整理
         │
         ▼
  車速預測引擎（30–60 分鐘）
         │
         ├──────────────┐
         ▼              ▼
  程式化數值／規則判定   官方交通管制知識庫
         │              │
         └──────┬───────┘
                ▼
       Agent：意圖解析與說明
                │
                ▼
       數值一致性檢查／回退
                │
                ▼
       使用者互動與行前資訊
```

**設計原則：** 預測數值與判定規則應由可驗證的程式或工具產生；LLM 主要處理使用者意圖與自然語言表達，不自行編造車速、管制措施或建議依據。

## 資料與評估規劃

| 項目 | 內容 |
| --- | --- |
| 資料來源 | 高速公路局 M05A 門架交通資料 |

| 模型評估 | 車速預測誤差、壅塞偵測能力 |
| Agent 評估（後續） | 回答正確性、數值一致性、證據可追溯性 |

### 目前初步觀察

- 車速預測誤差相較持續預測基準有所降低。
- 連續假期期間的改善幅度仍有限。
- 壅塞提前預警能力目前尚未觀察到明確優勢。
- Agent 回答正確性與證據可追溯性仍需進一步驗證。

以上屬於**初步研究觀察**；具體指標、實驗條件及統計結果應以後續正式實驗紀錄為準。
